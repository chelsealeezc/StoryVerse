# StoryVerse

StoryVerse 是一个帮助普通用户整理、理解并连接真实生活经验的叙事探索产品。

当前版本是中文 localhost / GitHub Pages 交互原型，包含：

- Icebreaker 暖场故事浏览
- 本地模拟注册与首故事门禁
- 四步 Story Input Wizard
- 模拟 AI 标签与叙事结构分析
- 城市、人生阶段、主题三维共鸣选择
- 五则首次推荐
- 轻量星图与故事卡片
- 喜欢、不喜欢、关闭与举报反馈闭环

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

产品规则与第一阶段范围见 [prd.md](./prd.md)。
