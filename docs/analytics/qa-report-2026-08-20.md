## 发现并修复

- `story_input_snapshot` 原来可能与普通队列混批；已改为立即、独立发送。
- `pagehide` 大请求可能超过浏览器 keepalive 上限；已按约 60KB 分批，常规批次按 250KB 控制。
- 匿名请求缺少 `Origin`、同批混合匿名身份和非法 viewport 原来不够严格；服务端已拒绝或安全降级。
- 首次共鸣确认误用了大厅 P0 事件；已拆为 P2 `resonance_confirm_clicked`，大厅重排仍使用 P0 `lobby_resonance_confirm_clicked`。
- 退出登录可能先销毁会话导致事件丢失；改为有限等待的 `trackBeforeNavigation`，实测退出事件到达。
- Three.js 星点缺少键盘/自动化可访问入口；增加视觉隐藏的语义按钮，复用同一打开逻辑且不改变界面。
- 管理员看板已重构为研究行为看板：移除性能/系统质量面板，增加共享筛选器、创作/发现/阅读/引导指标、旅程漏斗、每日活动、搜索/导航、事件分布和按登录账号下钻。
- 中等桌面宽度下筛选器原来会断成不规则三列；已改为稳定双列布局。账号下钻后原来停留在列表滚动位置；现会回到顶部并立即展示账号摘要。
- 事件时间线原来会直接显示大量英文代码事件名；现已为全部已注册行为补齐中英文可读名称，同时保留原始事件名便于核对。
- pgTAP 文件原来含两个 `plan()`，49 条断言实际运行后仍被 TAP 判失败；已合并为一个 49 条计划并通过。
- 本地 Edge Runtime 对超过 256KB 的请求会在传输层中止而非返回结构化 413；测试脚本增加 10 秒边界并把传输中止视为本地安全拒绝，线上仍严格验证 HTTP 413。
